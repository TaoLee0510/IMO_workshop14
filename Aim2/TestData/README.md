# Aim 2 data contract (TestData = synthetic example of the real Data/ format)

Scenario: **main**. Generated by `Code/testdata/make_testdata.R`. All values are synthetic.

Days are counted relative to CAR T infusion (day 0); lymphodepletion runs on days -5 to -3.
No calendar dates are stored. Units: ANC, PLT, WBC, ALC x10^9/L; Hb g/dL; CRP mg/L; ferritin ng/mL.

| File | One row per | Columns |
|---|---|---|
| `patients.csv` | patient | patient_id, age, sex, product, costim, prior_lines, prior_asct, prior_bendamustine, months_since_last_chemo, bridging, ld_flu_total, ld_cy_total, ld_dose_reduced, crs_grade, crs_onset_day, crs_end_day, marrow_involvement, iec_hs, viral_infection, relapse_day, subsequent_tx_day, death_day, last_followup_day, phenotype_clinical (optional) |
| `labs_long.csv` | blood count | patient_id, day, anc, plt, wbc, hgb, alc, mcv (optional, fL), rdw (optional, %) (ANC below 0.01 reported as 0) |
| `inflam_long.csv` | inflammatory lab | patient_id, day, crp, ferritin |
| `events.csv` | intervention | patient_id, event (gcsf, plt_tx, rbc_tx, tpo_ra, cd34_boost, tocilizumab, steroid, anakinra), start_day, end_day, dose |
| `split.csv` | patient | patient_id, split (train/test), locked_at, seed |
| `mutation_tested.csv` | sequenced patient | patient_id, sample_day, sample_timepoint (apheresis/post_bridging/pre_LD), sample_type (PB/BM), lod_vaf, panel_version |
| `mutations_pre.csv` | variant (pre-treatment) | patient_id, gene, protein_change, vaf, depth. Tested patients without a row are **negative** |
| `post_samples_planned.csv` | planned post-treatment sample | patient_id, sample_day, sample_type, indication |
| `later/mutations_post.csv` | variant (post-treatment) | patient_id, sample_day, gene, protein_change, vaf, depth. Arrives later; read only after pre-registration |

`truth/` holds the generating parameters. Analysis steps never read it; only validation step V does.
